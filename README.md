# Twitch TD

Tower Defence в стиле dark fantasy для OBS, которой управляет Twitch-чат.

Шпаргалка для игроков — команды, классы, постройки, враги — в [CHEATSHEET.md](CHEATSHEET.md). Здесь — всё вместе с настройкой и устройством.

## Запуск

```bash
go run ./cmd/twitchtd -sim 12
```

- `http://127.0.0.1:8787/` — оверлей. В OBS добавляется как Browser Source 1920×1080.
- `http://127.0.0.1:8787/dev.html` — консоль разработчика: отправка сообщений в чат от любого ника, запуск волны, пауза, новая карта.

Флаги:

| Флаг | По умолчанию | Что делает |
| --- | --- | --- |
| `-addr` | `127.0.0.1:8787` | адрес сервера |
| `-sim` | `0` | число ботов-чатерсов для проверки без стрима |
| `-config` | `config.json` | переопределение баланса (необязательный файл) |
| `-seed` | время | seed генератора |
| `-web` | встроенные файлы | раздавать фронт с диска (`web/static`), чтобы правки JS подхватывались без пересборки |
| `-fresh` | выключен | не продолжать сохранённую партию, а начать новую (кошельки и души остаются) |

На стримерском ПК сервер запускают через `run.cmd`, см. «Релизы и обновление на стриме».

## OBS

- **Оверлей:** Browser Source с адресом `http://127.0.0.1:8787/`, 1920×1080. Включи «Control audio via OBS», чтобы звук игры шёл в микшер. Опцию «Shutdown source when not visible» лучше выключить.
- **Панель стримера:** «Док-панели → Пользовательские док-панели браузера», адрес `http://127.0.0.1:8787/panel.html`. В ней:
  - карта: выбери постройку и кликни по клетке, ставится мгновенно и без лимита; инструмент «Снести»;
  - волна сейчас, пауза, новая игра с выбором биома, призыв босса;
  - ХП стен, выдача золота из казны;
  - список наёмников с золотом и душами: +100 золота, запрет на стройку (`!tdban`/`!tdunban`), освобождение из тюрьмы (`!tdfree`, у заключённого ник с ⛓), кнопка «Выгнать» (`!tdkick`);
  - заявки на мемкоины: «Выдано» или «Отказать» с возвратом душ;
  - микшер звука: общая громкость, «без звука», эмбиент и шесть групп (бой, стройка, волны и боссы, донаты и награды, таверна, стены и наёмники); ▶ играет пример прямо в оверлее, то есть в OBS;
  - баланс: лимиты построек, извилистость трассы, шансы гостей и ЭссДиЭфа, подъёмные, отключка от выпивки и другое. Правки применяются сразу и хранятся в базе поверх `config.json`.

По умолчанию общая громкость 20%, эмбиент выключен.

Звук синтезируется в браузере (WebAudio), файлов не нужно. Модераторы управляют им из чата:

| Команда | Действие |
| --- | --- |
| `!tdvolume 0-100` | общая громкость (заодно снимает «без звука») |
| `!tdmute` | выключить или включить весь звук |
| `!tdambient on\|off\|0-100` | эмбиент: включить, выключить или задать громкость |
| `!tdsound группа 0-100\|on\|off` | громкость группы: бой, стройка, волны, донаты, таверна, стены |
| `!tdsound` | ответ в чат с текущими уровнями |

`config.json` перечитывается на лету, как только файл сохранён. Настройки интеграций (Streamer.bot, DonationAlerts) и путь к базе требуют перезапуска.

## Подключение Streamer.bot

1. В Streamer.bot: **Servers/Clients → WebSocket Server**. Включи сервер (по умолчанию `127.0.0.1:8080`) и, если нужно, авторизацию с паролем.
2. Создай рядом с программой `config.json`:

   ```json
   {
     "streamerbot": { "enabled": true, "url": "ws://127.0.0.1:8080/", "password": "пароль, если включён" }
   }
   ```

3. Запусти `twitchtd`. В логе появится `streamer.bot: connected`.

Игра сама подписывается на `Twitch.ChatMessage` и `Twitch.PresentViewers`. Отвечает в чат запросом `SendMessage`: по умолчанию от бот-аккаунта, `"sendAsBot": false` переключает на аккаунт стримера. Если хочется отвечать через своё действие, задай `"replyAction": "Имя действия"`: игра запустит его с аргументом `message`. Ответы собираются в одно сообщение не чаще раза в 1,5 с, чтобы не упереться в лимиты Twitch.

Сообщения стримера (роль broadcaster) строят мгновенно и без лимита, модераторам доступны команды `!td*`.

**Эмодзи в репликах.** В репликах `!s` эмодзи показываются картинками: Twitch приходит вместе с сообщением от Streamer.bot, BTTV, FFZ и 7TV тоже, если они включены в его настройках. Кроме того, оверлей сам загружает глобальные наборы 7TV, BTTV и FFZ, а также эмодзи каналов из `config.json`:

```json
{ "emoteChannels": ["ha5turr", "xqc", "123456789"] }
```

Канал можно указать ником или числовым ID. Ники сервер при запуске сам переводит в ID через публичный api.ivr.fi (туда уходят только ники из списка); канал, который не нашёлся, пропускается с записью в лог. Если у двух каналов есть эмодзи с одинаковым названием, побеждает тот, что в списке раньше, поэтому свой канал лучше ставить первым. Старая настройка `twitchChannelId` тоже работает и считается первой в списке. Сабовые Twitch-эмодзи чужих каналов так не подтягиваются: их картинки приходят только вместе с сообщением. Анимированные (GIF, WebP) играют как в чате.

**Стример играет на равных.** Галочка «Стример играет из чата на равных» в панели (`"streamerPlays": true` в `config.json`) превращает стримера в обычного игрока. Его сообщения из чата идут под его ником: кошелёк и золото за сообщения, лимит построек, наёмник в таверне с классом и навыками, очередь приказов и кулдауны, АФК, души, ачивки и звания. Он считается в сложности, как любой чатер. Команды `!td*` из чата при этом работают. Панель стримера остаётся «рукой бога»: постройки с карты в панели по-прежнему бесплатные и мгновенные.

Боты из `ignoreUsers` (Nightbot, StreamElements, бот канала hasturyan и т. п.) игнорируются.

Каждый ответ игры начинается с `/me` (`"replyPrefix"` в разделе `streamerbot`), чтобы сообщения бота выделялись в чате. Пустая строка отключает префикс.

### Проверка без Twitch

`cmd/fakesb` изображает Streamer.bot: отвечает на рукопожатие, проигрывает короткий сценарий чата и печатает ответы игры. Строки, набранные в его консоли как `логин: текст`, уходят в чат.

```bash
go run ./cmd/fakesb -password devpass
```

```bash
go run ./cmd/twitchtd -config configs/dev-fakesb.json
```

## Поддержка: баллы канала, биты, подписки, донаты

Всё начисляется в кошелёк чатерса с потолком (`walletCap`). То, что не влезло, уходит в **общую казну**: она постепенно чинит стены таверны (`treasuryGoldPerSec`), а стример может раздать её командой `!tdtreasury ник N`. Казна видна в верхней панели. По умолчанию казна переживает конец игры и перезапуск сервера; галочка «Хранить казну между играми» в панели (`keepTreasury`) выключает это, и каждая новая игра начинается с пустой казной.

**Награды за баллы канала** создаются в Twitch как обычно. Игра узнаёт их по названию (`rewards` в `config.json`):

| Название по умолчанию | `action` | Что делает |
| --- | --- | --- |
| HTD: Мешок золота | `gold` | +300 золота |
| Починить стены | `repair` | +200 ХП стенам |
| Дождь стрел | `strike` | 50% макс. ХП каждому врагу (боссам 10%) |
| Выпивка за мой счёт | `round` | каждому в таверне случайный напиток с его эффектом |

**Лимит на игру для одного зрителя:** поле `perUser` у награды (0 или нет поля — без лимита). Счётчик свой у каждого зрителя, переживает перезапуск сервера и обнуляется с новой игрой. Лишнюю покупку игра не выполняет, пишет зрителю в чат и просит Streamer.bot вернуть баллы. Ключ `rewards` в `config.json` заменяет весь список, поэтому перечисли в нём все награды:

```json
"rewards": [
  { "title": "HTD: Мешок золота",   "action": "gold",   "amount": 300, "perUser": 3 },
  { "title": "Починить стены",      "action": "repair", "amount": 200 },
  { "title": "Дождь стрел",         "action": "strike", "amount": 50 },
  { "title": "Выпивка за мой счёт", "action": "round" }
]
```

Чтобы баллы возвращались:

1. Twitch разрешает отменять покупку только той программе, которая создала награду. Поэтому награду с лимитом создай в Streamer.bot (**Platforms → Twitch → Channel Point Rewards**, правый клик → **Add**), а не в панели Twitch. **Skip Reward Requests Queue** оставь выключенным: автоматически выполненную покупку отменить нельзя.
2. Создай действие, например `TD Refund`, с подзадачей **Core → C# → Execute C# Code**:

   ```csharp
   using System;

   public class CPHInline
   {
       public bool Execute()
       {
           CPH.TryGetArg("rewardId", out string rewardId);
           CPH.TryGetArg("redemptionId", out string redemptionId);
           return CPH.TwitchRedemptionCancel(rewardId, redemptionId);
       }
   }
   ```

3. В `config.json`, в разделе `streamerbot`, добавь `"refundAction": "TD Refund"`.

Без `refundAction` лимит всё равно работает, но баллы за лишнюю покупку не возвращаются (в логе будет строка `not refunded`).

**Биты:** 8 золота за бит (`bitsGold`). **Подписка:** 400 (`subGold`). **Подарочная подписка:** 400 дарителю и 150 получателю (`giftRecipientGold`).

### DonationAlerts

1. На <https://www.donationalerts.com/application/clients> создай приложение с адресом перенаправления `http://127.0.0.1:8787/da/callback`.
2. В `config.json`:

   ```json
   { "donationalerts": { "enabled": true, "clientId": "…", "clientSecret": "…" } }
   ```

3. Запусти игру и открой `http://127.0.0.1:8787/da/login`, затем разреши доступ. Токен хранится в базе и обновляется сам. Статус виден в консоли `dev.html`.

Курс: 100 ₽ заполняют пустой кошелёк (`donationGoldPerRub`: 10). Другие валюты переводятся в рубли по `currencyRub`.

**Чей это донат?** Имя в DonationAlerts — свободный текст, поэтому игра ищет владельца так:
1. код из `!link` в сообщении доната (`TD-4821`): после первого такого доната имя донатера запоминается навсегда;
2. имя, привязанное раньше;
3. совпадение с ником чатерса;
4. иначе — в общую казну.

## Сохранение

Кошельки чатерсов и текущая партия сохраняются в SQLite (`twitchtd.db`, путь задаётся полем `db`) каждые 10 секунд и при выходе. После перезапуска партия продолжается на той же карте с теми же башнями. Прерванная волна играется заново, а недостроенное возвращается владельцам золотом. Флаг `-fresh` начинает новую партию, кошельки при этом сохраняются.

## Релизы и обновление на стриме

Версия игры — `Version` в [internal/game/version.go](internal/game/version.go), формат X.Y.Z: X — глобальная версия (0 в раннем доступе), Y — мажорный патч, Z — минорный (фиксы, хотфиксы). Её видно в оверлее и в панели, а `!tdversion` пишет её в чат.

**Ветки.** `dev` — работа, `master` — стабильная версия, `release` — то, что уезжает на стрим. Вливается только в одну сторону: `dev` → `master` → `release`.

**CI (GitHub Actions).** Каждый пуш в `master`/`dev` и каждый PR (в том числе в `release`) гоняет `go vet` и тесты (`.github/workflows/ci.yml`). Пуш в `release` выпускает версию (`.github/workflows/release.yml`): берёт `Version`, ставит тег `vX.Y.Z`, собирает `twitchtd.exe` под Windows и публикует GitHub Release вместе с его SHA-256. Если такой тег уже есть (версию забыли поднять), релиз останавливается и ничего не перезаписывает. Оба файла лежат в `master` и приезжают в `release` вместе с кодом.

**Выпустить версию:**

1. Поднять `Version` в `internal/game/version.go`, закоммитить, слить в `master`.
2. Влить `master` в `release`: с телефона — PR `master` → `release` в приложении GitHub и кнопка Merge, с компьютера:

   ```bash
   git push origin master:release
   ```

3. Через пару минут релиз появится на GitHub, после этого `!tdupdate` в чат.

Совет: в настройках репозитория на GitHub (Settings → Rules → Rulesets, или Branches → Branch protection) защитить ветку `release`: вливать только через PR и только при зелёной проверке `ci`.

**Запуск на стримерском ПК** — не через `go run`, а через сторожа [run.ps1](run.ps1) в папке проекта:

```powershell
.\run.cmd
```

`run.cmd` можно запускать и двойным кликом или ярлыком: он вызывает `run.ps1` с `-ExecutionPolicy Bypass` только для этого запуска, так что системную политику PowerShell менять не нужно (иначе Windows ответит «выполнение сценариев отключено в этой системе»). Флаги сервера передаются ему же (`.\run.cmd -addr 127.0.0.1:8787`). Если `twitchtd.exe` ещё нет, скрипт собирает его через Go. `config.json` и `twitchtd.db` лежат рядом. Сторож перезапускает сервер после обновления и после падения (через 3 с), Ctrl+C останавливает всё. Режим выделения мышью (QuickEdit) в окне сторожа выключен: в обычной консоли Windows клик в окно замораживает всё, что в него пишет, и обновление «зависало» до нажатия клавиши. Если остановка сервера при обновлении или `!tdrestart` почему-то затянется дольше 20 секунд, он завершится сам, и сторож всё равно запустит новую сборку.

**Обновление прямо на стриме**, с телефона, командой в чате (стример и модераторы):

| Команда | Что делает |
| --- | --- |
| `!tdupdate` | находит последний релиз на GitHub; если он новее, качает `twitchtd.exe`, сверяет SHA-256, ждёт фазы стройки (волну не рвёт), сохраняет игру и перезапускается на новой версии. Бот пишет в чат каждый шаг и итог: «таверна обновлена до vX» |
| `!tdrollback` | возвращает прошлую сборку тем же путём |
| `!tdrestart` (`!tdперезапуск`) | перезапускает ту же сборку сразу, не дожидаясь фазы стройки: сервер сохраняется, перечитывает `config.json` и продолжает партию (прерванная волна играется заново). Работает только при запуске через `run.cmd` |
| `!tdversion` | текущая версия |

Партия после перезапуска продолжается: переигрывается только волна, которая шла (а обновление ждёт фазы стройки). Если новая сборка не запустилась или упала в первые 30 секунд, `run.ps1` сам возвращает прежнюю, а бот пишет «vX не запустилась, вернулась vY». Без `run.ps1` (например, при `go run`) `!tdupdate` только скажет, что обновление недоступно.

Репозиторий, откуда берутся релизы, задаётся в `config.json`: `"update": {"repo": "ha5turr/twitchTD"}` (по умолчанию он и есть). Для приватного репозитория добавь `"token"` — токен GitHub с правом только на чтение содержимого.

**Хотфикс с телефона, целиком:** правка в Claude Code (облако или Remote Control) или прямо на GitHub, с поднятой `Version` → PR в `master` → PR `master` → `release`, Merge → дождаться релиза → `!tdupdate` в чат.

## Баланс

Враг, дошедший до ворот, бьёт стены, а защитники на стенах ранят его (`gateDps`). Одна утечка стоит части ХП, а босс у ворот смертельно опасен.

`cmd/balance` прогоняет сотни партий без графики с ботами, которые ведут себя как чат: пишут, копят золото, строят у дороги, улучшают.

```bash
go run ./cmd/balance -games 40
```

Результат с настройками по умолчанию (v0.21.0, 40 партий на размер чата, партия на 60 минут):

| Чатерсов | Волн пережито (p10 / медиана / p90) | Длительность, мин (медиана) | Дошли до финала | Победили |
| --- | --- | --- | --- | --- |
| 1 | 4 / 9 / 14 | 15.0 | 0% | 0% |
| 3 | 9 / 16 / 23 | 26.3 | 0% | 0% |
| 5 | 9 / 19 / 29 | 29.3 | 5% | 0% |
| 10 | 9 / 24 / 38 | 37.6 | 20% | 10% |
| 20 | 9 / 24 / 36 | 36.0 | 18% | 0% |

Флаг `-ready` заставляет ботов голосовать `!готов`, как только им нечего тратить. При 10 ботах такие команды доходят до финала реже (15%), зато выигрывают его почти всегда (12%): темп окупается. Боты заметно слабее живого чата (2–4 живых игрока за час доходили до 40-й волны), поэтому сила финала подобрана так, чтобы половина доживших до него ботов его выигрывала: живой команде он должен даваться с трудом, но без гарантии.

Результаты собираются у волн с боссом (5, 10, 15…), поэтому медиана прыгает между ними, и разница в одну такую ступень между прогонами — обычный разброс.

Цель из дизайн-документа: при 10–20 чатерсах партия заканчивается на 15–25 волне и длится около 30 минут. Стример в симуляции не строит, на живом стриме партии будут чуть длиннее. Боты чинят свои баррикады, когда у тех остаётся меньше половины прочности. Один чатерс в одиночку не держит первого босса на 5-й волне. ЭссДиЭф приходит не раньше 10-й волны (`sdfFromWave`): когда он выпадал уже на 5-й, команда почти никогда его не сдерживала, и p10 для любого размера чата падал до 4 волн. Чтобы сравнить вариант настроек, передай его файлом: `-config candidate.json`. Флаг `-biome swamp` (или `ruins`, `dungeon`, `crypt`, `ice`) играет все партии в одном биоме. Крипта обычно самая тяжёлая, подземелье — самое лёгкое.

Все числа лежат в `internal/game/config.go` (`DefaultConfig`). Любое из них можно переопределить в `config.json`:

```json
{ "walletCap": 1500, "towerLimit": 4, "webcamFrom": "N1", "webcamTo": "P5" }
```

## Как устроена игра

Чатерсы — наёмники, живущие в таверне на левом краю экрана. Они строят башни на поле и защищают таверну от волн нежити. Стример строит мгновенно и без лимита, а с `streamerPlays` — наравне со всеми.

### Игровой цикл

- **Партия — час на подготовку и финал.** Часы партии (60 минут, `matchMinutes`, в панели) идут и в стройку, и в волну, стоят на паузе стримера и хранятся в сохранении, так что перезапуск и обновление сервера их не сбрасывают; пока сервер выключен, время не идёт. Сколько осталось, видно в верхней панели, а за 30, 10, 5 и 1 минуту до финала бот пишет в чат.
- **Финал.** Когда время вышло, текущая волна доигрывается, после неё идёт обычная стройка, а следом — **финальная волна**: оба босса биома во главе волны. Сила финала привязана к часам, а не к номеру волны: он такой, как волна 38 (`finalWave`), боссы ещё в 1,5 раза сильнее (`finalBossMult`). Поэтому команда, которая спешила, встречает того же противника, но с бо́льшим запасом золота и уровней. Выстояли финал — **победа**: экран итогов, ачивка «Час выстоян» и вдвое больше душ (`soulsWinMult`). Стены пали раньше — поражение.
- **После партии** игра ждёт команды `!нк [биом]` (или `!tdnew`). Если в панели задать «Новая карта сама через, с» (`gameOverSec`), новая карта начнётся сама.
- **Стройка и волна чередуются.** Фаза стройки длится 35 секунд, перед первой волной на новой карте 60. Строить, улучшать и чинить можно и во время волны, но наёмник рискует попасть под удар.
- **`!готов`** (`!go`) — голос за то, чтобы начать волну раньше. Когда готово больше половины игроков в таверне, волна начинается через 5 секунд (`readyCountdownSec`). Каждая сэкономленная секунда стройки приносит каждому, у кого есть постройки, 1 золото (`tempoGoldPerSec`), не больше 30 за волну (`tempoGoldMax`); с наградами за боссов растёт и эта. Спешка выгодна, но враги растут с каждой волной, так что торопиться без запаса рискованно.
- **Каждая 5-я волна — босс**, на волне босса, начиная с 10-й, с небольшим шансом приходит ЭссДиЭф.
- **Итоги.** В конце партии экран итогов показывает победу или поражение, время, волну и лучших по урону, убийствам и выпивке; участники получают души. Золото сбрасывается до стартового, если в настройках не включено `keepGold`.
- **Формат — перерывы стрима.** Цикл «стройка + волна» занимает около 100 секунд, за час в обычном темпе — 30–35 волн. Не доиграли — пауза: партия и её часы сохраняются и продолжаются в следующий перерыв или на следующем стриме. Сцену в OBS можно скрывать: состояние живёт на сервере.

### Карта и биомы

- **Поле 16×10** в шахматной нотации: колонки A–P слева направо, строки 1–10 снизу вверх. Враги появляются справа и идут по утопленной в землю дороге к воротам таверны слева.
- **Каждая игра — новая случайная карта** в одном из пяти биомов, тот же биом не выпадает дважды подряд. Биом задаёт форму дороги, препятствия, врагов и боссов. Seed карты виден в верхней панели.
- **Извилистость трассы** (`pathCurve`, в панели, от 0 до 1, по умолчанию 0,5) действует со следующей карты. При 0 трассы такие, как задуманы биомом. Чем больше, тем сильнее дорога петляет змейкой: идёт вверх-вниз, а не прямо к таверне, с разворотами, и каждый отрезок не короче двух клеток. При 0,5 трасса длиннее примерно на 6 клеток, при 1 — на 10–15, поэтому партии немного длиннее. Сохранённая партия после перезапуска восстанавливается с той извилистостью, с которой была создана.
- **Руины:** длинная извилистая дорога, мало препятствий.
- **Подземелье:** стены-препятствия, меньше мест под стройку.
- **Крипта:** длинные прямые участки и кладбища, призраки проходят сквозь баррикады.
- **Ледяные пещеры:** короткая дорога, лёд ускоряет врагов на 15%, часть врагов не замедляется холодом (капканы замедляют всех).
- **Болото:** извилистая тропа между тёмными прудами; летучие мыши срезают углы по прямой, слизни делятся при смерти.
- **Зона вебки** (по умолчанию N1–P5) не занята дорогой, строить там нельзя.

### Наёмники

- **В игру входят командой.** `!play` (`!играть`) или любая игровая команда (`!b`, `!drink`, `!кости` и т. д.) сажает наёмника со случайным классом в таверну. Просто сообщения в чате дают золото, но не добавляют наёмника и не повышают сложность, так что зашедшие поздороваться и ушедшие не делают волны тяжелее. `!помощь` в игру не вводит. Выйти самому можно командой `!leave`. Над ним в таверне ник в цвете звания и золото.
- **Приказы.** По `!build`, `!up` или `!чинить` наёмник выходит из ворот, идёт к клетке, работает и возвращается. Ходьба прячет задержку стрима. В очереди до 3 приказов.
- **Оглушение.** Враг, задевший наёмника, оглушает его: наёмник убегает в таверну, отдыхает и потом возвращается к работе. Прогресс не теряется.
- **Кто считается активным.** Игрок, который вошёл в игру (`!play` или любая игровая команда) и писал за последние 10 минут (`activeWindowMn`). Только активные влияют на сложность, да и то по вкладу в постройки (см. «Сложность»). В таверне сидят они и те, у кого есть постройки или наёмник на поле. Постройки ушедших продолжают стрелять.

### Тюрьма

Камера встроена в стену таверны слева от камина. Над заключённым — ник и обратный отсчёт срока, его реплики показываются под камерой. Любой игрок может предложить посадить другого: `!тюрьма ник` — например, разбойника, который надоел кражами. Голосование идёт 45 с (`jailVoteSec`), голос предложившего засчитывается «за», обвиняемый не голосует; пока оно идёт, доска в таверне показывает «Суд таверны» со счётом. Игрока сажают, если «за» не меньше двух (`jailMinYes`) и больше, чем «против». Если проголосовали все, кто сейчас в таверне, итог подводится сразу. Оправданного нельзя снова судить 5 минут (`jailRetrySec`), а отсидевшего — до конца игры.

За решёткой:
- его постройки продолжают стрелять, а бонус класса на них остаётся;
- способности класса не срабатывают (в том числе кражи разбойника и пантера друида), музыка барда стихает;
- нельзя строить, улучшать, пить, играть в кости и вообще пользоваться командами, кроме `!s` и `!выкуп` (ставка в костях, если он сидел за столом, возвращается);
- если наёмник был в поле, он доделывает уже отданные приказы и возвращается прямо в камеру.

Срок — 3 минуты (`jailSec`). Выйти раньше можно `!выкуп`, и он тем дороже, чем меньше игрок вложил в игру. Вклад считается так же, как для сложности: вложенное в постройки против половины медианы остальных. Кто построил свою долю, платит 30 (`jailRansomMin`); кто не построил ничего — половину медианы вложенного остальными (`jailRansomPct`); между ними — пропорционально. Больше половины кошелька выкуп не бывает. Платить можно только из кошелька, подъёмные не принимаются. Сумма фиксируется в момент посадки, выкуп уходит в казну. Стример может освободить кого угодно: `!tdfree ник` или кнопка в панели. Перезапуск сервера тюрьму не открывает.

### Классы

Класс даёт фирменной постройке +30% (`classBonus`). Строить можно что угодно, бонус действует только на свою постройку. `!class` показывает класс, `!class маг` меняет его один раз за игру, но только пока у игрока нет артефактной постройки. Готовая способность не тратится на первых врагов волны: она ждёт, пока на поле не станет хотя бы трое (или не выйдут последние враги волны).

### Золото

Валюта одна — золото, у каждого свой кошелёк с потолком (1000 по умолчанию). Тратится на постройки, улучшения, починку, выпивку и ставки в кости.

| Источник | Сколько |
| --- | --- |
| Старт | 120 |
| Сообщение в чате | 5, не чаще раза в 45 с |
| Присутствие (Present Viewers) | 10 тем, у кого уже есть наёмник |
| Убийство | награда за врага тому, чья башня добила |
| Ассист | 50% награды сверху каждому барабанщику, ускорявшему добившую башню, и владельцу капкана, ранившего врага |
| Баррикада держит врагов | 0,5 в секунду за каждого |
| Конец волны | 10 + 2 × номер волны каждому, у кого есть постройки |
| Разбойник | раз в минуту тащит немного у соседа по таверне |
| Святилище | доля награды за каждое чужое убийство на карте, по вкладу святилища в урон |
| Алтарь проклятий | «осколок души» за смерть проклятого им врага: половина награды за него |
| Золотой голем (гость) | золотой дождь всем, кто по нему попал |
| Подъёмные | новичку с 5-й волны, только на постройки (см. «Сложность») |
| Баллы канала, биты, подписки, донаты | см. раздел «Поддержка» |

**Малая команда.** Если игроков меньше трёх, награды выше: соло получает за волну ×3, за убийства ×1,5 (вместе с ассистами, долей святилищ и осколками душ); вдвоём ×2 и ×1,25; с трёх игроков всё как обычно. Игроки считаются так же, как для сложности, — по вложенному в постройки, так что зашедший без построек зритель бонус почти не снижает. Множитель за убийства фиксируется в начале волны, за волну — в её конце; баннер «Волна отбита» показывает его. Настраивается в панели: `smallRewardSize` (с какого числа игроков награды обычные), `smallWaveMult`, `smallKillMult` (множители для соло, 1 — выключить).

После каждой волны с боссом убийства, ассисты, баррикады и награда за конец волны платят на 15% больше. Всё, что не влезло в кошелёк, уходит в общую казну, а казна чинит стены таверны. Игрок, который вошёл в игру и замолчал на 10 минут (ушёл в АФК), выходит из неё: его золото уходит в казну, а вернуться можно снова через `!play`. Кошельки, загруженные из базы, не трогаются. Боты (Nightbot, StreamElements и другие из `ignoreUsers`) игнорируются.

### Сложность

Сложность растёт с номером волны и с числом активных игроков N, которое фиксируется при старте волны. Каждый игрок входит в N не целиком, а по вкладу: полностью, если вложил в постройки хотя бы половину медианы остальных, иначе — долей (вложил 500 при нужных 1250 — считается за 0,4 игрока). Новичок без построек почти не утяжеляет волны, игрок, который только сидит в таверне, тоже.

- ХП врага: `baseHP × hpGrowth^волна × (1 + chatterHPCoef × √N)` (по умолчанию 30, 1.16 и 0.25);
- врагов в волне: `baseCount + countPerWave × волна + √N` (6 и 2);
- босс: ХП обычного врага × `bossHPMult` (10).

Корень сдерживает рост на большом чате: при 10–20 активных ХП врагов примерно вдвое выше базового. Все коэффициенты меняются в `config.json` или в панели.

**Подъёмные новичкам.** Игрок, который впервые за игру входит в неё с 5-й волны (`grantFromWave`), получает разовые подъёмные — половину медианы вложенного в постройки остальными активными игроками (`grantPct`). Подъёмные лежат отдельно от кошелька, потолок 1000 их не ограничивает, и тратятся только на постройки и улучшения, раньше своего золота. При продаже, поломке баррикады и возврате за клоуна доля, купленная на подъёмные, уходит в казну, а не игроку. `!leave` и уход в АФК сжигают остаток, повторный вход в ту же игру новых подъёмных не даёт. Остаток виден в `!me`.

Как это работает:

- **Броня** врага срезает физический урон: у мумии 50%, у тролля 35%. Магический урон обелиска и жаровни, поджог и кровотечение броню игнорируют.
- **Цель.** Атакующие постройки бьют того, кто дальше всех прошёл по дороге в пределах их дальности. Снаряд летит за целью; если она умерла по пути, жаровня всё равно взрывается в точке прицела.
- **Где строить.** Капканы и баррикады — только на дорогу, остальное — на свободные клетки рядом с ней. Призраки проходят сквозь баррикады и не задевают капканы.
- **Лимит** — 5 построек на игрока в начале игры (`towerLimit`), +1 после каждой волны с боссом, до 10 (`towerLimitMax`). Если в игре один-два игрока, каждому ещё +2 (`smallTeamBonus`). Чат узнаёт о росте лимита сразу после победы над боссом. Если лимит упал (например, в игру зашли новые игроки), стоящие постройки не трогаются, просто нельзя ставить новые. Клоуны в лимит не входят. Стример строит без лимита и мгновенно, если не включён `streamerPlays`.
- **Стройка.** Наёмник идёт от таверны к клетке со скоростью 2,6 клетки/с и строит 3 с (улучшение — 2 с). Одновременно у игрока до 3 заказов.
- **Продажа** (`!sell C4`) возвращает 60% вложенного, включая улучшения. Сломанная баррикада возвращает 50% (Воителю 75%).
- **Ярость при осаде.** Враг, которого баррикада держит дольше 15 секунд (`siegeRageSec`), впадает в ярость: краснеет, перестаёт лечиться (своя регенерация, тролли и лекари не помогают) и бьёт баррикаду с каждой секундой сильнее, на +10% урона в секунду (`siegeRagePerSec`). Если враг снова пошёл, ярость проходит. То же самое у двери таверны: враг, который ломится в ворота дольше 15 секунд, перестаёт лечиться и бьёт стены всё сильнее. Баррикады и дверь задерживают волну, но бесконечно держать её не могут.
- **Бонус класса** +30% к своей постройке: урон, поджог, аура, лечение, прочность.

Каждая постройка улучшается до 5 уровня (цвета редкости: белый, зелёный, синий, фиолетовый, оранжевый).

#### Артефактный уровень

Постройку **своего класса** можно поднять ещё на уровень — до **6-го, артефактного** (красная точка). Улучшение стоит цена × 6, урон и остальные характеристики продолжают расти по множителю улучшения, а постройка получает особую силу. Постройки чужого класса, клоун и друид (у него нет классовой постройки) остаются на 5. Пока у игрока стоит артефакт, сменить класс нельзя, а силы артефакта работают, только пока он остаётся постройкой класса своего владельца. Артефакт видно по шестой, красной точке у края клетки. За первый артефакт даётся ачивка «Хранитель реликвии», а за то, что все постройки, какие игрок может поставить, — его классовые (у жреца — все 4 святилища), ачивка «Однолюб».

#### Улучшения

`!up C4` поднимает постройку на уровень. Улучшение до уровня N стоит цену постройки × N: пост лучников до 2 уровня — 120, до 5 — 300. Всего за постройку 5 уровня уходит 15 её цен (лучники — 900, святилище — 1125).

Основная характеристика растёт в «множитель улучшения» раз за уровень. У поста лучников это ×1,40, у обелиска и жаровни ×1,45, у тотема ×1,48, у капканов ×1,55 (они слабее на старте, но сильнее к концу игры), у клоуна ×1,35, у святилища, барабанов и баррикады — ×1,5. Ауры растут линейно, на половину базового значения за уровень. Дальность, скорострельность и площадь взрыва от уровня не зависят.

| | прыжков | 3 | 3 | 4 | 4 | 5 |
| Клоун | урон по ЭссДиЭфу, % его макс. ХП (×1,35) | 0,5% | 0,68% | 0,91% | 1,23% | 1,66% |

Сверху к этому добавляются бонус класса (+30% ко всем характеристикам из таблицы у своей постройки, кроме зарядов и частоты), святилища, барабаны и выпивка. Святилища и барабаны складываются: два святилища 5 уровня дают +90% урона. Сеть баллисты держит одинаково на любом уровне (2 с, радиус 0,7), меняется только частота. Починка баррикады стоит долю от цены её текущего уровня, а при поломке возвращается 50% всего вложенного, включая улучшения (Воителю 75%).

### Враги и боссы

| Биом | Враги | Боссы (каждая 5-я волна, по очереди) |
| --- | --- | --- |
| Руины | скелеты, гули, культисты-лекари, подрывники (с 5-й волны), щитоносцы (с 6-й) | Костяной Рыцарь (щит 5 с, затем 10 с без него), Вожак Культа (раз в 14 с поднимает двух культистов-лекарей) |
| Подземелье | пауки, крысы, тролли с регенерацией, подрывники (с 5-й волны) | Королева Пауков (паутина на башни, паучата), Пещерный Тролль (камнем оглушает башню) |
| Крипта | скелеты, мумии, призраки, некроманты-лекари, щитоносцы (с 6-й волны) | Лич (поднимает скелетов), Призрачный Король (телепорт вперёд) |
| Ледяные пещеры | скелеты, ледяные скелеты, инеистые духи, щитоносцы (с 6-й волны), подрывники (с 8-й) | Ледяной Голем (замораживает башни), Демон Стужи (ускоряет всех врагов) |
| Болото | слизни, гули, летучие мыши (со 2-й волны), подрывники и гоблины-шаманы (с 4-й) | Болотная Ведьма (раз в 8 с превращает лучшую постройку рядом в лягушку на 8 с), Гидра (отращивает голову за каждую потерянную четверть ХП, если рана не горит) |

**Гоблин-подрывник** быстрый и хрупкий: дойдя до первой баррикады, взрывается и сносит половину её прочности (два подрывника ломают её совсем). Награды за него никто не получает, так что сбивать его надо до баррикады.

**Слизень** при смерти делится на двух слизнят (по 40% его ХП), слизнята больше не делятся. **Летучая мышь** летит по прямой от входа к воротам, над баррикадами и капканами, срезая повороты тропы. **Гоблин-шаман** раз в 4 с смывает с соседей в радиусе 1,6 клетки сети, ожоги, проклятия, кровотечение и замедление — его стоит убивать первым.

**Гидра** рождается с 3 головами. Каждый раз, когда она теряет ещё четверть ХП, отрастает новая голова: +15% к скорости и +30% к урону по стенам за каждую лишнюю. Если в этот момент гидра горит (жаровня, пиромант, метеоры), рана прижигается и голова не растёт. Число голов видно в полоске босса.

**Щитоносец** медленный и крепкий: под его щитом (радиус 1,2 клетки, полупрозрачный купол) он сам и все соседи получают вдвое меньше физического урона. Магия, огонь, кровотечение и навыки щит пробивают.

#### Гости

На обычной (не босс) волне с 3-й (`eventFromWave`) с шансом 15% (`eventChance`, оба в панели) в середине волны приходит гость с полоской здоровья, как у босса, и баннером:

- **Сборщик податей** идёт за **казной**. Стены не бьёт, но дойдя до ворот, забирает половину казны и уходит. Убили — казна получает бонус (30 + 10 × номер волны, растёт с наградами за боссов).
- **Золотой голем** никого не атакует и быстро бежит через карту. Убили — **золотой дождь**: 40 + 15 × номер волны золота (тоже растёт с наградами) делится между всеми, кто по нему попал, по доле урона, каждому хотя бы монета. Убежал — ничего страшного, просто без золота.

Стример может позвать гостя командой `!tdspawn tax_collector` или `!tdspawn golden_golem`.

#### ЭссДиЭф

Гость любого биома и нарочно нечестный босс. На волне босса он приходит вместо обычного с шансом `sdfChance` (по умолчанию 20%, настраивается в панели), но не раньше волны `sdfFromWave` (по умолчанию 10-й, тоже в панели), так что первый босс на 5-й волне всегда обычный. Командой `!tdspawn sdf` стример может позвать его в любой момент.

- Очень медленный, в 15 раз больше ХП, чем у обычного босса, броня 30%. С каждой 5-й волной идёт на 10% быстрее, до двукратной скорости.
- Каждые 9 секунд он останавливается на 2 секунды, по очереди рыгает или пукает и кричит «УЗРИТЕ ВИЖН!». При этом он случайно делает одно из:
  - выключает все постройки в радиусе 3 клеток на 5 секунд;
  - сносит постройки в радиусе 1,6 клетки, без возврата золота;
  - сходит с тропы на 7 секунд и бродит по полю;
  - редко (один трюк из десяти) на 4 секунды переносится в таверну и отнимает до 50 золота у каждого присутствующего наёмника. Когда он умирает, украденное возвращается владельцам.
- Против него строят **клоуна** (`!b C4 clown`, 100 золота): клоун бьёт только ЭссДиЭфа, достаёт до него в любой точке карты (и в таверне), каждый выстрел снимает 0,5% его ХП. Клоуна можно поставить, только пока ЭссДиЭф на поле, у каждого не больше одного, в лимит построек он не входит. Трюки ЭссДиЭфа клоунов не трогают. После волны клоуны разбираются, золото за них возвращается полностью.
- Стример может вызвать его командой `!tdspawn sdf`.

### Выпивка

Каждый напиток меняет урон твоих построек (выстрелы, капканы, молнии):

| Напиток | Цена | Эффект |
| --- | --- | --- |
| Эль | 10 | все твои постройки +50% на 20 с, потом похмелье −50% на 20 с |
| Медовуха | 25 | случайная твоя постройка бьёт вдвое сильнее, другая случайная вдвое слабее, на 30 с |
| Чёрное зелье | 60 | все твои постройки +50% на 20 с, без похмелья |

Награда «Выпивка за мой счёт» наливает каждому в таверне случайный напиток с его эффектом.

**Опьянение.** Эль — 1 кружка в крови, медовуха — 2, зелье — 4; одна кружка выветривается за 90 с. Кто набрал 8 кружек (`passOutMugs`), перебирает и падает под стол: 90 с (`passOutSec`) наёмник храпит и не слышит игровых команд, включая `!leave` (раз в 20 с бот напоминает, сколько ещё спать). Постройки и навыки класса при этом работают. В первый раз даётся ачивка «Забулдыга» (+2 души). Свалить может и чужой раунд «Выпивка за мой счёт».

### Враги со временем

- Все враги понемногу лечатся: 0,2% максимального ХП в секунду (`enemyRegen`), тролли быстрее. Капкан на 3 секунды и любой поджог вдвое режут лечение, в том числе от культистов и некромантов, а враг в ярости (у баррикады или у двери таверны дольше 15 с) не лечится совсем.
- После каждой волны с боссом награды растут на 15% (`rewardGrowth`): за убийства, ассисты, удержание баррикадой и конец волны. В новой игре множитель сбрасывается.

### Души и ачивки

Души — валюта, которая остаётся между играми и хранится в базе.

- **В конце игры** их получают только те, кто нанёс урон за эту игру: 5% оставшегося золота, 1 за каждые 250 урона и 0,2 за убийство, не больше 80 за игру. За победу в финале — вдвое больше, и потолок тоже вдвое выше. Итог пишется в чат.
- **Ачивки** дают немного душ: обычные 2–6, сложные и скрытые до 10. Их 22, из них 5 скрытых. Получение показывается на оверлее и в чате.
- **Мемкоины:** `!мемы N` списывает 10 душ за мемкоин и создаёт заявку (одна открытая на человека, до 50 мемкоинов). У MemeAlerts нет официального API для начисления зрителю, поэтому стример начисляет вручную и отмечает заявку в панели («Выдано» или «Отказать» с возвратом душ) или командой `!tdmeme`.
- **Звания** растут от душ, полученных за всё время (трата душ звание не снижает): Неофит (серый, 0), Ученик (белый, 50), Скиталец (зелёный, 200), Первопроходец (синий, 500), Странник (фиолетовый, 1200), Эталон (оранжевый, 3000), Полубог (золотой, 7000). В таверне ник окрашен в цвет звания, звание видно в карточке `!me`, в ответах `!me` и `!души`; новое звание объявляется на оверлее и в чате. Души, выданные `!tdsouls`, тоже идут в звание.
- Все числа настраиваются в config.json: `soulsGoldPct`, `soulsPerDamage`, `soulsPerKill`, `soulsGameCap`, `soulsPerMemecoin`, `memeMax`.

## Устройство

- `internal/game` — симуляция: сетка, генерация карт по биомам, волны, башни, экономика, команды. Числа баланса — в `config.go`, версия — в `version.go`.
- `internal/server` — игровой цикл (20 тиков/с) и WebSocket `/ws`: снапшоты наружу, сообщения чата внутрь.
- `internal/sim` — боты для режима симуляции.
- `internal/streamerbot` — клиент WebSocket API Streamer.bot (авторизация, подписка, разбор событий, отправка сообщений).
- `internal/store` — SQLite: кошельки, души, ачивки, заявки на мемкоины и сохранённая партия.
- `internal/updater` — поиск и скачивание релиза с GitHub для `!tdupdate`; `cmd/twitchtd/update.go` — сами команды обновления и отката.
- `run.ps1` / `run.cmd` — сторож сервера на стримерском ПК; `.github/workflows` — CI и выпуск релизов.
- `cmd/fakesb` — поддельный Streamer.bot для локальной проверки.
- `cmd/balance` — симулятор баланса.
- `web/static/panel.html` — панель стримера; `js/audio.js` — синтез звука; `js/particles.js` — эффекты.
- `web/static` — оверлей на PixiJS (без сборки, ES-модули) и консоль разработчика. Встраивается в бинарник через `go:embed`.
